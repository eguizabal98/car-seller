# Technology Stack

## Core Framework
*   **Next.js 16**: The React framework for the web, utilizing the App Router for routing and layouts.
*   **React 19**: The latest version of the library for web and native user interfaces.
*   **TypeScript**: Strongly typed superset of JavaScript for better developer experience and code quality.

## Styling & UI Components
*   **Tailwind CSS 4**: Utility-first CSS framework for rapid UI development.
*   **Radix UI**: Headless UI primitives for accessible and customizable components (Dialog, Popover, Slider, etc.).
*   **Lucide React**: Beautiful & consistent icon library.
*   **Sonner**: An opinionated toast notification component.
*   **Embla Carousel**: A lightweight carousel library with fluid motion and great swipe precision.
*   **Next Themes**: Perfect dark mode implementation for Next.js.
*   **Class Variance Authority (CVA)**: For creating variant-based component styles.

## State Management
*   **Zustand**: A small, fast, and scalable bearbones state-management solution. Used for global state like the comparison tool.

## Forms & Validation
*   **React Hook Form**: Performant, flexible and extensible forms with easy-to-use validation.
*   **Zod**: TypeScript-first schema declaration and validation library.
*   **@hookform/resolvers**: Bridges Zod with React Hook Form.

## Backend & Database
*   **Supabase**: Open source Firebase alternative.
    *   **PostgreSQL**: The underlying relational database.
    *   **Auth**: Secure user authentication.
    *   **Storage**: For storing vehicle images and documents.
*   **@supabase/ssr**: Supabase utilities for Next.js Server Components and Server Actions.

## Utilities
*   **date-fns**: Modern JavaScript date utility library.
*   **clsx & tailwind-merge**: Utilities for constructing `className` strings conditionally.

## Testing & Quality Assurance
*   **Playwright**: Reliable end-to-end testing for modern web apps.
*   **ESLint**: Pluggable linting utility for JavaScript and TypeScript.

## Deployment
*   **Vercel**: The platform for frontend frameworks and static sites, built to integrate with your headless content, commerce, or database.
